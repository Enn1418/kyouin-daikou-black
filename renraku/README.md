# れんらく — その日の記録から保護者向けの手紙を作る

特別支援学級（出席番号1〜7番）向け。
その場で吹き込んだ・打ち込んだ気づきを、児童ごとの短い手紙にして、感熱紙50mm幅に印刷します。

**設計の全体像と検討の経緯は [../docs/parent-letter-workflow/PLAN.md](../docs/parent-letter-workflow/PLAN.md) にあります。**

---

## はじめる前に（必ず）

**勤務校・教育委員会の生成AI利用規程と、児童の情報の取り扱いについて確認してください。**
この仕組みは実名をAIに渡さない作りになっていますが、それは規程の確認の代わりにはなりません。

---

## 1. 準備（初回だけ・15分）

```bash
# 1) 名簿を作る（このファイルは絶対にコミットされません）
cp roster.example.csv roster.private.csv
# → 出席番号1〜7に、実際の氏名・呼び名・表記ゆれを書く

# 2) 画像を作るためのライブラリ（印刷を始めるときでOK）
pip install Pillow
```

> **⚠ 実名を書くのは `roster.private.csv` です。`roster.example.csv`（見本）には絶対に書かないでください。**
> 見本のほうは Git で管理されており、**GitHubに公開されます**。
> 書き込む前に、ファイル名が `.private.` になっていることを必ず確認してください。
> 誤って見本のほうを使うと、実行時に警告が出ます。

### 名簿の書き方

```csv
出席番号,氏名,手紙での呼び名,表記ゆれ
1,山田 太郎,たろうさん,たろう;太郎;タロウ;たろうくん
```

**「表記ゆれ」列が実は一番大事です。** 音声の文字起こしは「たろう」「太郎」「多郎」と揺れます。
普段その子を呼ぶときの言い方を、思いつくかぎり `;` 区切りで入れてください。
あとから追記していけば精度が上がっていきます。

## 2. 毎日の流れ

### その場で（10秒 × 数回）

**名前 → 場面 → できごと** の順に、話し言葉のまま。

> 「**たろうさん**、**給食**で、**自分からおかわりって言えた**」

名前を最初に言うのがコツです。あとの振り分けが自動でできます。

- **音声レコーダーの場合**: 文字起こし結果を `records/<今日の日付>/00_raw.md` に貼り付ける
- **キーボードの場合**:
  ```bash
  python3 tools/add.py "たろうさん、給食で自分からおかわりって言えた"
  ```
  時刻は自動で付きます。その日のフォルダも自動で作られます。

### 放課後（5分）

```bash
claude
```
```
> 今日の手紙を作って
```

Claude が次を行います。

1. `tools/mask.py` で実名を出席番号に変換（`00_raw.md` → `01_masked.md`）
2. 出席番号ごとに記録を整理（`10_split.json`）
3. 手紙の下書きを作成（`letters/1.md` など）
4. `children/1/history.md` に記録を追記
5. **記録がなかった児童を報告**（翌日の観察の手がかり）

### 確認（1〜2分）

手紙の先頭には、根拠になった記録がコメントで入っています。

```markdown
<!-- 根拠: 09:20 朝の会 日直の号令を自分から / 12:30 給食 自分からおかわり -->

#1は今日、朝の会で日直の号令を自分から言うことができました。…
```

**本文と根拠を見比べるだけ**で確認が済みます。1通15秒。おかしければその場で書き直します。

### 印刷

```bash
python3 tools/render_letter.py --all records/<日付>   # 画像化（ここで実名に戻る）
python3 tools/print_letter.py --all records/<日付>    # 既定は preview（印刷しない）
```

プリンター購入前は `preview` のままで大丈夫です。`print/*.png` を開けば仕上がりが確認でき、
普通紙に印刷して渡すこともできます。

## 3. 個人情報の守り方

実名が現れるのは**両端の2か所だけ**です。真ん中の工程はすべて出席番号で動きます。

```
00_raw.md          実名あり ── ローカルのみ。Claude は読みません
   ↓ tools/mask.py（名簿で機械的に置換。AIは介在しません）
01_masked.md       #1〜#7 のみ ── ここから先をAIが扱います
   ↓ Claude
letters/3.md       #3 のまま
   ↓ tools/render_letter.py（名簿で復元）
print/3.png        「じろうさん」── 印刷用。ローカルのみ
```

仕掛けは3つです。

- **`.gitignore`** — `roster.private.csv`、`records/`、`children/` はコミットされません
- **`.claude/settings.json`** — Claude が `00_raw.md` と `roster.private.csv` を読むことを
  ツールレベルで禁止しています（うっかり読ませることができません）
- **他児の名前を出さない** — 手紙に `#5` が残っていても、印刷時に「おともだち」に置き換わります

**それでも残るリスク**: 手紙の本文そのものは、児童の様子の記述です。氏名がなくても、
記述内容から個人が推測されうることは変わりません。**匿名化は万能ではありません。**

## 4. コマンド一覧

| やること | コマンド |
|---|---|
| その日のフォルダを作る | `python3 tools/new_day.py` |
| 記録を1行足す | `python3 tools/add.py "けんたさん、帰りの支度が5分で"` |
| 実名 → 出席番号に変換 | `python3 tools/mask.py` |
| 手紙を作る | Claude に「今日の手紙を作って」 |
| 印刷用画像を作る | `python3 tools/render_letter.py --all records/<日付>` |
| 印刷する | `python3 tools/print_letter.py --all records/<日付>` |
| 今週の偏りを見る | Claude に「今週の振り返り」 |

サンプル（架空の児童7名）で一通り試せます。

```bash
python3 tools/mask.py --roster sample/roster.csv sample/records/2026-08-11
python3 tools/render_letter.py --all --roster sample/roster.csv sample/records/2026-08-11
```

## 5. 調整のしどころ

### 文字が小さい・大きい

`tools/render_letter.py` の冒頭:

| 設定 | 既定 | 意味 |
|---|---|---|
| `BODY_SIZE` | 26 | 本文の文字サイズ。大きくすると紙が長くなります |
| `LINE_GAP` | 11 | 行間 |
| `THRESHOLD` | 165 | 2値化のしきい値。**印字がかすれるなら上げる** |
| `WIDTH` | 384 | 印字幅48mm。50mm級はほぼこの値 |

### 文体が自分と違う

`.claude/skills/letter/SKILL.md` に、**自分が過去に書いた手紙を3通そのまま貼ってください。**
ルールを言葉で説明するより、実例のほうが正確に伝わります。

### 児童の振り分けを間違える

名簿の「表記ゆれ」列に、間違われた言い方を足します。
`tools/mask.py` は、ある児童の照合語が別の児童の照合語に含まれる場合（「ゆう」と「ゆうた」など）に
警告を出します。

## 6. プリンターを買うとき

**印字幅48mm / 384ドット**のものを選べば、`render_letter.py` はそのまま使えます。

| 候補 | 接続 | `--backend` |
|---|---|---|
| Phomemo M02 系（シール紙が使える） | BLE | `phomemo-ble` |
| 58mm ESC/POS レシートプリンタ | USB | `escpos-usb` |
| 同上 | Bluetoothシリアル | `escpos-serial` |

接続情報（USBのID、COMポート、BLEアドレス）は `tools/print_letter.py` の冒頭にまとめてあります。

```bash
pip install python-escpos     # ESC/POS の場合
pip install bleak             # Phomemo BLE の場合
```

**感熱紙の印字は数か月〜数年で薄くなります。** 手紙は「その日の速報」と位置づけ、
原本は `records/` に残る文面を正とし、学期末に普通紙でまとめて渡すのがおすすめです。
