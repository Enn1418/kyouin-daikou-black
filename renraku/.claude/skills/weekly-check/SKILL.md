# 週次チェック — 記録の偏りを見つける

手が掛かる児童ほど記録が増え、落ち着いている児童ほど記録が減ります。これは意識していても
起きます。**そこを機械に見張らせるのが、この仕組みの本命です。**

## 手順

1. 直近7日分の `records/*/letters/*.md` を数える（ファイル名が出席番号）。
2. `children/<出席番号>/history.md` の最終更新日を見る。
3. 出席番号1〜7の全員について、次の表を出す:

   | 出席番号 | 今週の手紙 | 最後の記録 | 状態 |
   |---|---|---|---|
   | 1 | 3通 | 8/11 | |
   | 3 | 0通 | 8/4 | ⚠ 1週間記録なし |

4. 手紙が**2通未満**の児童を明示する。
5. その児童について、`children/<出席番号>/history.md` から**どんな場面の記録が多いか**を見て、
   翌週に観察できそうな場面を1〜2個だけ提案する（例:「6番は音楽の記録が続いています。
   図工や休み時間の様子はまだ記録がありません」）。

## 注意

- 実名は扱いません。出席番号のまま報告してください。
- 記録が少ないこと自体を問題として書かないこと。**翌週の観察の手がかり**として示します。
- 「全員に均等に」を目標にしない。週に最低2通を全員に、が現実的な目安です。
