# 動かし方（Windows）

初回だけ 15 分ほど。2 回目以降はショートカット 2 つをダブルクリックするだけです。

---

## 0. 用意するもの

- **Chrome か Edge**（3D 表示に WebGPU を使うため。Windows なら Edge が最初から入っています）
- **Claude の API キー** — <https://console.anthropic.com/settings/keys> で作れます（`sk-ant-` で始まる文字列）
- **Node.js** — 次の手順で入れます

git は要りません。

---

## 1. 取り込む（初回だけ）

### 1-1. Node.js を入れる

<https://nodejs.org/ja> を開き、**「LTS」** と書かれたボタンからインストーラをダウンロードします。
ダブルクリックして、あとは「次へ」で進めるだけです（設定を変える必要はありません）。

これはアプリを動かすための土台です。1 回入れれば以後は不要です。

### 1-2. ファイル一式をダウンロードする

次のリンクを開くと ZIP が落ちてきます。

<https://github.com/Enn1418/kyouin-daikou-black/archive/refs/heads/claude/teacher-focused-design-kv19k9.zip>

（`main` にはまだ入れていないので、開発中のブランチを直接ダウンロードする形です。約 1.2 MB）

### 1-3. 展開する

ダウンロードした ZIP を右クリック →「すべて展開」。
展開先はどこでも構いませんが、たとえば `C:\kyouin-app` にします。

展開すると `kyouin-daikou-black-claude-teacher-focused-design-kv19k9` という長い名前のフォルダが
できます。**扱いやすいよう `kyouin-app` などに名前を変えて構いません**（以下この名前で説明します）。

### 1-4. そのフォルダで「ターミナル」を開く

エクスプローラで `kyouin-app` フォルダを開き、**上部のアドレスバー**（`C:\... \kyouin-app` と
表示されている場所）をクリックして、そこに

```
powershell
```

と入力して **Enter**。青い画面の窓が開きます。これが「ターミナル」です。
以降の「コマンド」は、この窓に文字を入力して Enter を押すことを指します。

> Windows 11 ならフォルダを右クリック →「ターミナルで開く」でも同じです。

### 1-5. 部品を集める

開いた窓に、次の 1 行を入力して Enter。

```powershell
npm install
```

数分かかり、大量の文字が流れます。**それが正常です。** 途中で警告（`warn`）が出ても問題ありません。
入力できる状態に戻ったら完了です。

これで「取り込む」は終わりです。

> **あとから更新したくなったら**: もう一度 ZIP をダウンロードして展開し直し、`npm install` をやり直します。
> 頻繁に更新するなら git を使うほうが楽ですが、最初は ZIP で十分です。

## 2. 教材フォルダを作る（初回だけ）

**手で作る必要はありません。** 場所を決めるだけで、次の手順 3 でブリッジが自動的に作ります。

### 場所を決める

どこでも構いません。決めるのは「**教材をためていく場所**」です。

| PC の状況 | 使う場所 | 手順 3 で打つコマンド |
|---|---|---|
| **C ドライブだけ**（多くの PC） | `C:\Users\（あなた）\kyouin` | `npm run bridge -- --root "$env:USERPROFILE\kyouin"` |
| D ドライブがある | `D:\kyouin` | `npm run bridge -- --root "D:\kyouin"` |

**ユーザー名を調べる必要はありません。** PowerShell では `$env:USERPROFILE` が
`C:\Users\（あなた）` に自動で置き換わります。そのまま打ってください。

> ドキュメントフォルダの下に置きたくなりますが、OneDrive がドキュメントを同期していると
> 場所がずれて分かりにくくなります。`$env:USERPROFILE\kyouin`（＝ユーザーフォルダ直下）が
> 迷いません。エクスプローラのアドレスバーに `%USERPROFILE%` と打つと、その場所が開きます。

### 何ができるのか

手順 3 でブリッジを起動すると、**フォルダが無ければ**次の形が自動で作られます。

```
kyouin\
  00_共通\
    学級の実態.md          ← ★ これだけ書き換えます（雛形が入っています）
    自立活動_区分項目.md    ← 自立活動を使うとき、告示の本文を貼ります
    書式\
  01_教材\  国語\ 算数\ 自立活動\
  02_個別\
  03_印刷テンプレート\
  99_記憶\
    memory.md              ← 差し戻した指摘が自動で溜まります
```

**すでに中身のあるフォルダを指定した場合は、何も作りません。** 担任が用意したものに
勝手に混ぜないためです（足りないものだけ足したいときは `--init` を付けます）。

### 書き換えるのは 1 ファイルだけ

`00_共通\学級の実態.md` をメモ帳（またはワードパッド）で開き、実際の学級に合わせて直します。
雛形には A児・B児・C児の例が入っているので、**上書きしていくのが早い**です。

```markdown
## A児（1年）
- 国語: ひらがな清音は読める。拗音・促音が不安定
- 算数: 10までの数唱と1対1対応
- 集中: 10分。切り替えに予告が要る
```

**氏名は書きません。** A児・B児という記号だけにします。氏名との対応は、
このフォルダの外（紙か別の場所）で管理してください。ここに対応表を置いた時点で、
「個人情報を入れない」という前提が崩れます。

> **なぜ手で作らせないのか**: Windows は既定でファイルの拡張子を隠すため、
> メモ帳で「学級の実態.md」と保存したつもりが `学級の実態.md.txt` になります。
> また文字コードが UTF-8 でないと日本語が文字化けします。
> どちらもブリッジが作れば起きません。

## 3. 起動する（毎回）

**ターミナルを 2 つ**開きます。どちらも手順 1-4 と同じやり方で、`kyouin-app` フォルダの中で開いてください。

### ターミナル 1 — 教材フォルダのブリッジ

```powershell
npm run bridge -- --root "$env:USERPROFILE\kyouin"
```

（D ドライブに置くなら `--root "D:\kyouin"`）

`--root` の前の `--` は必要です（無いと npm 自身の引数として扱われます）。

**フォルダがまだ無ければ、ここで雛形ごと作られます。** 作ったものが一覧で表示されます。
そのあとトークンが表示されるので、この行をあとで使います。
トークンは教材フォルダの中に保存されるので、**次回以降も同じものが出ます**（貼り直しは要りません）。

```
  教材フォルダ ブリッジを起動しました
  フォルダ : D:\kyouin
  URL      : http://localhost:5174
  トークン : 3f9a1c...
```

### ターミナル 2 — アプリ

```powershell
npm run dev
```

### ブラウザで開く

```
http://localhost:3000/kyouin-daikou-black/
```

`http://localhost:3000/` だけだと 302 で転送されます。**末尾の `/kyouin-daikou-black/` まで**入れてください。

## 4. 設定を入れる（初回だけ）

画面右上の **鍵アイコン** をクリックします。

1. **Claude API Key** に `sk-ant-...` を貼る
2. **教材フォルダ（任意）** の左に `http://localhost:5174`、右にターミナル 1 のトークンを貼る
3. **接続を確認** を押す → フォルダ名（`kyouin`）が緑で出れば成功
4. **Save**

キーもトークンもブラウザに保存され、次に開いたときは**自動で接続し直します**。
右上のフォルダのアイコンが緑なら繋がっています（灰色＝未設定、赤＝繋がらない）。

> 接続に失敗する場合: ターミナル 1 が動いているか、ポート番号が合っているかを確認してください。
> **ブリッジが動いていなくてもアプリは使えます**（ファイルの読み書きだけができません）。

---

## 5. 動かす

1. 画面右上の **歯車アイコン** でチーム画面を開き、**「特支・同時異教材室」** を選ぶ（既定で選ばれています）
2. 職員室に戻り、**授業デザイナー**（リード）をクリックして話しかける
3. 題材を渡す

```
明日の算数。題材は「かさ（LとdL）」。45分。
A児・B児・C児の3段階でプリントを作って。
B児は前回、単位の書き忘れが多かった。
```

学年も実態も書きません。`00_共通/学級の実態.md` を読みに行きます。

4. カンバンに 3 つのタスクが並び、教材A・B・C が同時に動きます
5. 出てきたものを読み、直したいところがあれば**差し戻す**（その指摘は `99_記憶/memory.md` に残り、次回から最初からそうなります）
6. 承認すると `D:\kyouin\01_教材\…` に保存されます。`.html` が印刷用です

止めるときは、両方のターミナルで **Ctrl+C**。

## 6. 2 回目以降を楽にする

デスクトップにショートカットを 2 つ作っておくと、ダブルクリックだけで起動できます。

メモ帳で次の内容を書き、`bridge.bat` という名前で（「ファイルの種類」を「すべてのファイル」にして）保存します。

```bat
cd /d C:\kyouin-app
npm run bridge -- --root "%USERPROFILE%\kyouin"
```

（`.bat` の中では `$env:USERPROFILE` ではなく `%USERPROFILE%` と書きます）

同じく `app.bat`。

```bat
cd /d C:\kyouin-app
npm run dev
```

`C:\kyouin-app` の部分は、実際に展開した場所に置き換えてください。

## うまくいかないとき

| 症状 | 見るところ |
|---|---|
| 画面が真っ暗 | Chrome か Edge か（WebGPU 非対応のブラウザでは 3D が出ません） |
| 404 になる | URL の末尾が `/kyouin-daikou-black/` になっているか |
| 鍵アイコンが赤いまま | Save を押したか。キーの前後に空白が入っていないか |
| 接続を確認が押せない | URL とトークンの両方が空欄でないか（どちらかが空だと押せません） |
| 接続を確認が失敗する | ターミナル 1 が動いているか。トークンをコピーし損ねていないか |
| フォルダのアイコンが赤い | ターミナル 1 を閉じていないか。閉じていたら `npm run bridge` から起動し直す |
| 教材フォルダに保存されない | 接続確認が緑になっているか（未接続だとエージェントにファイル機能が渡りません） |
| `npm run bridge` で root がおかしい | `--root` の前に `--` があるか |
| 教材フォルダの雛形が作られない | すでに中身のあるフォルダを指定している（意図的にそうしています）。足りないものだけ足すなら `--init` を付けて起動 |
| `学級の実態.md` が文字化けする | 手で作ったファイルの文字コードが UTF-8 でない。ブリッジに作らせた雛形を使うのが確実 |
| `npm` は認識されていません、と出る | Node.js が入っていない、または入れた後にターミナルを開き直していない |
| ターミナルの開き方が分からない | フォルダのアドレスバーに `powershell` と入力して Enter（手順 1-4） |

## 何が動いているのか

- **ターミナル 1（ブリッジ）** — 教材フォルダだけを読み書きする小さなサーバ。`127.0.0.1` にしか
  応答せず、トークンを要求し、指定フォルダの外には出ません。削除はできません
- **ターミナル 2（アプリ）** — 画面。生成 AI との通信はブラウザから直接行われ、
  ブリッジには API キーを渡していません

詳しくは [`teacher-edition-design.md`](./teacher-edition-design.md)、
使い方の流れは [`teacher-edition-workflow.md`](./teacher-edition-workflow.md) にあります。
