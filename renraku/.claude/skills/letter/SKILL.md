# 保護者向け「その日の手紙」を作る

## 絶対の前提

- **`00_raw.md` は読まない。`roster.private.csv` も読まない。** どちらも児童の実名を含みます。
  読んでよいのは `01_masked.md`（実名が `#1`〜`#7` に置き換わったもの）だけです。
- 手紙の中でも児童は **`#3` のように出席番号のまま**書きます。実名への復元は印刷の直前に
  `tools/render_letter.py` がローカルで行います。
- **記録にないことは書かない。** 記録が1件もない児童の手紙は作りません。空欄を埋めたくなっても、
  作文をしてはいけません。「今日は手紙がない」という事実のほうが、翌日の観察の手がかりになります。

## 手順

1. 対象日を決める（指定がなければ今日）。
2. 生ログを出席番号に変換する:
   ```bash
   python3 tools/mask.py records/<日付>
   ```
   「児童を特定できなかった記録」が報告されたら、**先生に確認してから**先に進みます。
   勝手に誰かの記録だと推測して割り当ててはいけません。
3. `records/<日付>/01_masked.md` を読む。
4. 出席番号ごとに記録をまとめ、`records/<日付>/10_split.json` に保存する:
   ```json
   { "1": ["09:20 朝の会 日直の号令を自分から。声も大きい", "12:30 給食 自分からおかわり"],
     "2": ["09:55 算数 繰り上がりで手が止まったが最後までやりきった"] }
   ```
5. 記録がある児童について `records/<日付>/letters/<出席番号>.md` を書く（→ 下の書き方）。
6. `children/<出席番号>/history.md` に、その日の記録を追記する（学期末の所見づくりに使います）:
   ```markdown
   ## 2026-08-11 (火)
   - 09:20 朝の会 日直の号令を自分から。声も大きい
   - 12:30 給食 自分からおかわり／ピーマンを一口
   ```
7. 最後に、次を報告する:
   - 手紙を作った出席番号
   - **記録がなかった出席番号**（明示すること。ここが翌日の観察の指針になります）
   - 判断に迷った点

## 手紙の書き方

### 構成（3文）

1. **事実** — どの場面で、何ができたか。記録にある事実だけ
2. **様子** — そのときの表情・声・取り組みぶり。記録に書かれている範囲で
3. **家庭へのひとこと** — 話題にしやすい問いかけ、またはねぎらいの一言

### 分量

**120〜200字。** 感熱紙50mm幅（1行あたり全角13文字前後）に印刷するため、これを超えると
紙が長くなりすぎて読みにくくなります。短くて具体的なほうが良い手紙です。

### 呼称

`#3` のように出席番号のまま書く。「〇〇さん」などの敬称は付けない（印刷時に自動で付きます）。

### 書くこと

- できたこと、挑戦したこと、続けられたこと
- 小さな変化（先週より長く座れた、自分から声をかけられた、など）
- 困っていた場面は、**乗り越えた過程とセット**で

### 書かないこと

- 記録にない推測。「楽しそうでした」も、記録になければ書かない
- 診断名や障害特性についての断定的な記述
- 他の児童との比較、順位づけ、評価的な言い回し
- 課題を課題のまま終える文。「〜に挑戦中です」「〜を一緒に練習しています」と現在進行形にする
- 他の児童の出席番号。どうしても触れる必要があるときだけ `#5` と書く
  （印刷時に「おともだち」に置き換わります）

### 出力の形

先頭に**根拠となった記録**をHTMLコメントで必ず書きます。印刷はされません。
先生はこのコメントと本文を見比べるだけで確認が済みます。

```markdown
<!-- 根拠: 09:20 朝の会 日直の号令を自分から / 12:30 給食 自分からおかわり -->

#1は今日、朝の会で日直の号令を自分から言うことができました。声もはっきり
していて、教室のうしろまで届いていました。給食では自分から「おかわり」と
言える場面もありました。おうちでも聞いてみてください。
```

`#1` の直後に空白を入れないでください（「たろうさん は」と不自然に空きます）。
また行頭を `# ` で始めないでください（見出し記号として除去されます）。

## 印刷まで進めるとき

先生から「印刷して」と言われたら:

```bash
python3 tools/render_letter.py --all records/<日付>   # 画像を作る（実名はここで戻る）
python3 tools/print_letter.py --all records/<日付>    # 既定はプレビュー（印刷しない）
```

実機に接続済みなら `--backend escpos-usb` などを付けます。設定は
`tools/print_letter.py` の冒頭にまとまっています。
