# 担当図鑑 — 誰に何を頼めるかの索引

担任の指摘（2026-08-24）:

> キャラクター紹介ページを別建てで作ってほしい。各仕事の仮想キャラを一覧表示できるということ。

---

## 1. 何のためか

部屋の中にいる担当は、**話しかけないと何をする子か分からない**。
10部屋・41人になった今、「この仕事は誰に頼めばいいのか」を思い出す手段が要る。

`viewMode: 'characters'`（`src/interface/CharacterBook.tsx`）。ヘッダーの「図鑑」から開く。
並び順はフロア図と同じ（受付→設計→制作→仕上げ→点検→発信）。並びが違うと探し直しになる。

一覧は顔、開いたら全身。**絵が1枚も無くてもページとして成立する**（図形の顔が出る）。

## 2. 紹介文は手で書いた

`src/data/agentProfiles.ts` に41人ぶん。`tagline`（一言）と `bio`（2〜3文）。

役割そのものはモデルへの指示文（`description`）に書いてあるが、あれは「あなたは〜です」で
始まる硬い文で、人に読ませるものではない。**指示文を要約したものであって、新しい仕事を
足していない。** ここに書いていないことは、その担当はやらない。

生成に書かせなかったのは、やらない仕事を書いてしまうと索引として使えなくなるため。

## 3. 絵 — 形と色は揃え、個性は服だけ

担任の判断（2026-08-24）: **人物にしたいが、3Dのフォルムとかわいらしさは保つ。衣装で個性を出す。**

3Dの職員室では、全員が `public/models/character.glb` **1つのモデルを担当の色で塗り分けて**
動いている。紹介ページの絵もその姿に揃える。別人が並んでいると、3Dで見かけたあの子と結びつかない。

したがって生成の指示は、形（丸い頭と体がひと続き・短い手足・点の目・小さな笑み）と
色（`agent.color` 一色）を全員固定し、**変えてよいのは服と持ち物だけ**にしてある
（`AGENT_PROFILES.outfit`、`src/core/office/agentArt.ts`）。

これは見た目の統一のためだけではない。**人物の絵を41枚生成すると、役割ごとに
性別や年齢の偏りが自動的に出る。** マスコット人形の姿に固定すれば、その偏りをそもそも作らずに済む。

### 表情は生成しない

状態（待機・作業中・相談中・保留）は図形で描く（`AgentFace.tsx`）。
生成画像にすると 4状態 × 41人 = **164枚**必要になる。
生成に任せるのは「その子らしさ」だけで、**1人1枚**（顔・全身の2枚）。

## 4. 絵柄をそろえる — 見本を先に1枚

1枚ずつ独立に生成すると、41人の画風がばらける。担任の求めは「ある程度似ていればよい」。

そこで2段階にした:

1. **見本を1枚描く**（約20円）。気に入るまでここで描き直す
2. 決まったら**残りをまとめて描く**。見本を参照画像として渡すので、絵柄が寄る

先に41人ぶん描いてから「やっぱり違う」となると、そのぶんが丸ごと無駄になる。
見本の段階で止められるようにしてあるのは、そのため。

見本は `90_職員室/見本/default.png`、顔は `90_職員室/顔/`、全身は `90_職員室/全身/`。
置き場所はブリッジ側（`bridge/assets.mjs`）が決めるので、アプリから渡せるのは種類と id だけ。

### 費用

1枚 $0.067 ≒ 10円。1人＝顔と全身の2枚で約20円、41人で**約820円**。
一度描けば教材フォルダに残るので、毎回はかからない。

## 5. 担任だけは姿と色を変える（2026-08-25）

担任の判断: **担任だけフォルムを変え、他と被らない色にしたい。**

§3 では「全員そろえる」としていたが、担任については改める。職員室でただ一人の人間なので、
40人と同じだるま型だと関係が見えない。**質感と光は共通のまま、形だけ人型にする**
（`TEACHER_FORM`、`src/core/office/agentArt.ts`）。並べても浮かないのはそのため。

性別や年齢が読み取れる描き方を禁じている。これは担任自身を指す絵なので、
特定の見た目を割り当てると、本人と違うものを毎日見せることになる。

**見本は担任には渡さない。** 見本はだるま型なので、参照させると人型の指示に逆らって
丸い形に引き戻される。

### 色 — 測って決めた

以前の #7EACEA（水色）は、秘書室などの青灰色と**通常視で 1.10、P型色覚で 1.02**。
事実上おなじ色で、唯一の人間が他に埋もれていた。

担当41人の色は**明度50〜85に固まっている**ので、色相をずらすだけでは足りない
（黄緑や緑は、明るさが同じせいで橙や既存の緑と混ざる: 実測 1.01〜1.30）。
空いているのは**暗い側の明度帯**で、そこに置いた金茶 **#A16207** がすべて通った:

| | 通常 | P型 | D型 |
|---|---|---|---|
| 白いカードの上 | 4.92 | 3.65 | 3.32 |
| 暗い背景の上 | 3.99 | 5.46 | 5.98 |
| 黄 #FACC15 と区別 | 3.21 | 2.79 | 2.67 |
| 橙 #FB923C と区別 | 2.18 | 2.35 | 2.38 |

色を変えると**3Dの担任の体もこの色になる**。3Dは1つのモデルを色だけ変えて並べているので
形は変えられず、3Dで担任を見分ける手がかりはこの色だけになる。
